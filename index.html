QUICK START

Your personal physics lab.

Pick an experiment and press Run, or choose a shape and click the canvas to place it. Select objects to edit their properties.

For springs, rods and ropes, click two objects, or an empty point and an object. Connections attach to object centres; an empty point becomes a fixed world anchor.

Reset restores your starting conditions. Editing a running or paused experiment first returns to those conditions. Changes are saved locally; Save file exports a portable JSON scene.
